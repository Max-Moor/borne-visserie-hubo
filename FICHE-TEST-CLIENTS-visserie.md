# Fiche de test de la borne visserie (10 minutes par client)

Consigne : ne rien expliquer. Donnez la tablette et dites « Vous voulez fixer quelque chose chez vous, essayez de savoir quoi acheter ». Observez, notez.

## Scénarios (un par client)
1. Accrocher une TV au mur du salon.
2. Fixer une étagère sur une cloison en plaque de plâtre.
3. Poser des lames de terrasse (ne pas connaître l'épaisseur : « Je ne sais pas »).
4. Fixer un miroir dans une salle de bain, sans connaître le type de mur.
5. Retrouver, avec la barre de recherche, de quoi monter un abri de jardin.
6. Comparer deux références de vis et choisir la moins chère à la pièce.
7. Identifier une vis qu'on a en main.
8. Terminer par la liste de courses : ajouter le matériel, l'imprimer ou la retrouver sur son téléphone.

## À observer
| Question | Réponse |
|---|---|
| Le client trouve-t-il tout seul le bon parcours ? (oui/non, temps) | |
| Une question le fait-il hésiter ? Laquelle ? | |
| A-t-il cliqué sur « Je ne sais pas » ? À quelle question ? A-t-il lu les « Hypothèses retenues » ? | |
| Comprend-il la taille (Ø × longueur) et l'allée ? | |
| Choisit-il une référence ? Laquelle, et pourquoi ? | |
| Utilise-t-il « Emplacement dans le rayon » ? | |
| A-t-il ajouté le matériel (embout, foret…) à sa liste ? | |
| A-t-il scanné le QR, copié ou imprimé la liste ? Laquelle de ces 3 options ? | |
| A-t-il utilisé la recherche en haut de l'accueil ? Qu'a-t-il tapé ? | |
| A-t-il comparé 2 ou 3 références ? Quel critère a décidé ? | |
| Aurait-il appelé un conseiller ? À quel moment ? | |
| Le mode « Aa » (lecture facile) l'a-t-il aidé ? | |
| A-t-il choisi le néerlandais ? Les textes étaient-ils clairs ? | |

## Questions à poser à la fin
1. Sur 10, à quel point la borne vous a aidé ? (note)
2. Qu'est-ce qui était le plus utile ?
3. Qu'est-ce qui manquait ou vous a perdu ?
4. Feriez-vous confiance à la taille de vis conseillée ?
5. L'utiliseriez-vous en magasin plutôt que d'attendre un conseiller ?

## Après 5 à 10 clients
Notez les 3 problèmes qui reviennent le plus, et consultez l'écran « Analyse » (« Je ne sais pas », matériel ajouté, tailles sans référence).
